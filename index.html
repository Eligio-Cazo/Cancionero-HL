Política de Privacidad – Cancionero HL

Última actualización: 19/11/2025

Desarrollador: Ing. Eligio Cazó

Correo de contacto: ezcazo@gmail.com

1. Información general

La aplicación Cancionero HL no recopila datos personales ni utiliza servicios externos. Todo el contenido funciona de manera local en el dispositivo.

2. Datos recopilados

La aplicación no recopila ni almacena ningún tipo de dato personal.

3. Acceso a Internet

La aplicación no utiliza Internet para su funcionamiento.

4. Permisos

La aplicación no solicita permisos especiales (cámara, ubicación, micrófono, almacenamiento externo, etc.).

5. Publicidad

La aplicación no incluye publicidad.

6. Información compartida

No se comparte ningún dato con terceros, ya que no se recopila información.

7. Cambios en la política

Esta política podría actualizarse. Cualquier cambio se publicará aquí mismo.
